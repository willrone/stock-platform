# stochastic 信号质量实验（策略内部参数，overlay 证伪后的下一维度）

> 2026-10-12。承接 `SHARPE_OVERLAY_EXPERIMENT.md` 结论：外围包装（止损/入场门/市场择时/
> vol 开关/组合择时）全部证伪 → 试改信号本身。
> 数据：`stochastic_signal_grid.json`（500宇宙 5×4 网格）/ `stochastic_signal_fullmarket.json`
> （全市场 4 格）/ `stochastic_signal_fullmarket_yearly.json`（全市场 4 格分年+邻格）。
> 口径：2023-05-12→2026-05-08，100 万，费率/仓位同基线，确定性引擎。

## ⚠️ 头号方法学发现：500 宇宙不可用于信号调参

**同一默认格（20/80 k14）在两个宇宙上夏普 0.64 vs 0.81**（500 宇宙 vs 全市场 5513）。
500 清单是基线为统计套利 O(N²) 限流选的"排序尾部"子集，**非随机样本**，
对单策略信号调参会系统性失真。→ **任何信号调参必须在全市场 5513 上验证**。

## 第一轮：500 宇宙 5×4 网格（现已作废，仅存档）

阈值(20/80,15/85,25/75,30/70,35/65) × K周期(7,10,14,21)：
- 网格最优 15/85 k14 夏普 0.87 / 收益 +196.8%
- 但 K 周期维度非单调（20/80 行：k7=0.26 / **k10=0.01** / k14=0.64 / k21=0.35）
- 高点和 0.01 的坑相邻 → 刀锋模式

## 第二轮：全市场 5513 外推验证（决定性）

| 格 | 500宇宙夏普 | **全市场夏普** | 全市场收益 |
|---|---|---|---|
| G0 默认 20/80 k14 | 0.64 | **0.807** | +102.4% |
| G1 15/85 k14（500最优） | 0.87 | **0.42（崩）** | +47.2% |
| G2 35/65 k21（500次优） | 0.83 | **0.32（崩）** | +28.0% |
| G3 35/65 k10 | 0.74 | **0.924** | +108.3% |

500 网格的排名**零外推性**：最优格全市场崩到 0.42。仅 G3 在全市场真实跑赢默认（0.924>0.807）。

## 第三轮：全市场分年 + 邻格（三关判定，G3 全不过）

| 格 | 夏普 | 2023 | 2024 | 2025 | 2026 | 交易数 |
|---|---|---|---|---|---|---|
| G0 默认 20/80 k14 | 0.807 | -13.3% | **+83.5%** | +11.6% | +14.0% | 1865 |
| G3 35/65 k10 | 0.924 | +12.8% | +31.2% | +29.3% | +8.8% | **7338** |
| N1 邻格 35/65 k14 | 0.379 | | | | | |
| N2 邻格 30/70 k10 | 0.711 | | | | | |

- **分年稳定 ❌**：G3 只在 2023(熊)/2025 跑赢，**2024 大涨年跑输默认 52pp**——
  短 K 高频（4× 交易数）在单边牛市被 whipsaw + 成本绞杀
- **邻格平台 ❌**：K 10→14（同阈值）夏普 0.924→0.379，0.55 断崖 → 刀锋
- **显著性 ❌**：单窗口单宇宙 + 网格挑选的最高点 + 4× 换手，多重比较过拟合

## 最终结论（夏普研究五轮全部收口）

| 轮次 | 杠杆 | 判定 |
|---|---|---|
| 1 | 止损 A/B | ❌ 毁胜率（61-69%→18-45%） |
| 2 | overlay 三杠杆 | ❌ 市场择时全败 / 个股门微效 / vol 开关刀锋 |
| 3 | 组合 vol 择时 | ❌ 无变体超单腿（稀释+自锁+阈值刀锋） |
| 4 | 信号网格 500宇宙 | ❌ 宇宙失真，排名零外推性 |
| 5 | 信号网格 全市场+分年 | ❌ 最优格 G3 是刀锋，三关全不过 |

**诚实答案**：现有 16 策略 + 全部可调信号参数（阈值/K 周期）+ 4 条外围路线，
**没有任何稳健、非刀锋、跨宇宙成立的夏普改善**。stochastic 默认配置
（全市场夏普 0.81 / 年化 26.6% / 回撤 -26% / 1865 笔）就是这套体系的天花板。
所有"提升"都是单点精调的过拟合。

**唯一未试的结构性杠杆**：风险平价配置（stochastic + factor_ranking + bollinger
按波动率倒数加权）——与已证伪的"静态 50/50 / vol 择时切换"机制不同
（横截面配权 ≠ 择时）。属行为变更，需用户批准后实施。
