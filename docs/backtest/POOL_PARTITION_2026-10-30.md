# 分池并行实验（Pool Partition）—— 2026-10-30

> 口径：3 年真实盘口径 = `lag=1` + `enable_tradability=True` + qlib official 全市场（5513 只）
> 策略：`honest_composite`（25 公式因子主线，`use_panel=False`），weekly，topk=60 / n_drop=5
> 费用：commission 0.0003 / slippage 0.0001 / cash_reserve 5% / 每腿 100 万
> 窗口：2023-05-08 → 2026-05-08（727 个交易日）
> runner：`backend/scripts/pool_partition_experiment.py`
> 产物：`data/backtest/pool_partition.json`

---

## 一、一句话结论

**分池并行 ❌ 证伪，并且它证伪了一个更大的命题：A 股多头策略的夏普天花板在 beta 层，不在选股层。**

分池后持仓**完全不重叠**，腿间日收益相关不降反升（ρ=0.90，随机分池 0.96），
高相关来自**共同的市场 beta**，不是"同池选 TopK 的持仓重叠"。

> **这推翻了 `CONCLUSION_2026-10-27.md` 第三节「决定性发现」的归因。**
> 该节把 0.75~0.79 的相关性归因为"都从同一股票池选 TopK → 持仓天然重叠"，
> 并据此推出"分散化被堵死、框架内上限 0.88~1.03"。
> **实测证明这个归因不成立**：把池切开、持仓完全不重叠后，相关性依然 0.90。
> 因此该节结论（框架内上限）依然有效，但**其给出的原因需要更正**，
> 且它列出的解法 B.5「换股票池」在机制上走不通。

## 二、实验设计与口径

### 假设

`CONCLUSION_2026-10-27.md` 第二节列出 12 个方向全部证伪，统一机制是
「提高因子集中度 → 夏普降、回撤升」，并推荐方向 **B.5「换股票池」**：
不同宇宙的 alpha 不同，且**降低与现有持仓的重叠**——
「这才是解开『分散化被堵死』的关键」（原文）。

数学上限：两条腿夏普各为 S、日收益相关 ρ，等权合成夏普 = `S·√(2/(1+ρ))`。
- ρ=0.79（现状）→ 提升 5.7%
- ρ=0.50 → 提升 20.0%
- ρ=0.30 → 提升 25.5%
- ρ=0.00 → 提升 41.4%

**这是本项目第一个有真实数学收益上限、且不依赖任何参数拟合的方向。**

### 切池方式

**臂 A（行业分池，主实验）**：申万一级行业（`data/industry/industry_map.json`，
32 个行业 / 5579 只）做**贪心平衡划分**——行业规模从大到小逐个塞进当前
股票数最少的池 → 各池规模尽量均衡（避免两腿风险不等价）。
切完后每池**独立**做横截面 z-score → 池内选 TopK → 持仓天然不重叠。

**臂 B（随机分池，对照）**：同样的池规模，按固定种子（20261030）随机分配。
用途：区分「分散化效应」与「行业结构效应」。

### 基线复现门

K=1 即全池单条（= 当前主线），必须逐位复现 `ALL_real_lag1_v2.json`：

```
honest_composite → total_return 0.35505797455182114
                    sharpe      0.8795668740640868
                    mdd        -0.1337121157482497
                    trades      1190
```

**实测逐位一致（diffs 为空）→ 本报告所有数字可比。**

| **基线 K=1（全池）** | 0.8661 | — | 0.8796 | — | +35.51% | −13.37% | 1190 |
| **industry_K2** | **0.9220** | **+6.45%** | 0.9110 | 0.9037 | +41.62% | −14.00% | 2374 |

## 四、三个被推翻的假设

### ① 「持仓重叠是高相关的原因」—— ❌ 错

分池后各池股票**完全不重叠**（切池代码断言 `overlap == 0`），
但腿间日收益相关 **ρ = 0.9037**（K=2）/ **0.8956**（K=4），
**比现有多策略之间的 0.75~0.79 还高**。

→ 那 0.75 的相关**不是**持仓重叠造成的。所有这些策略本质上是
"做多 A 股"的**同一个风险敞口**，换池换不掉 beta。

### ② 「ρ 是分散化的瓶颈」—— ❌ 方向反了

按公式 ρ=0.90 时合成夏普理论上只该提升 3%，实测 K=2 是 +6.45%（略超，
因为两腿夏普不等），K=3/K=4 **转负**。

原因：**多腿时单腿质量掉得比 ρ 降得快**。
K=2 腿均 0.911（**高于**基线 0.880），K=4 腿均 0.810（低于基线）。
池子越小 → 横截面越窄 → 单腿信号越弱 → 抵不过分散化红利。

### ③ 「池内 z-score 参照系变窄会伤害信号」—— ⚠️ 不是主因

K=2 时腿均夏普 0.911 > 基线 0.880（池内标准化**反而略好**，
因为剔掉了跨池的极端值干扰），但合成仍只有 +6.45%。
真正的衰减发生在 K≥3。

### 附带发现：行业结构提供**真实但不足**的降相关

同样池规模下：

| | 行业分池 | 随机分池 | 差 |
|---|---|---|---|
| K=2 腿间 ρ | **0.9037** | 0.9591 | −0.055 |
| K=2 合成夏普 | **0.9220** | 0.7577 | +0.164 |
| K=4 腿间 ρ | **0.8956** | 0.9589 | −0.063 |
| K=4 合成夏普 | **0.8168** | 0.7730 | +0.044 |

→ 行业结构确实降相关（0.96→0.90），且随机分池还额外损失了信号质量
（随机分池的腿均夏普 0.762/0.780 明显低于行业分池的 0.911/0.810）。
**但降相关的幅度远不足以抵消单腿质量损失。**

## 五、真正的结论（比"分池失败"更重要）

### A 股多头策略的夏普天花板在 **beta 层**，不在选股层

25 因子 / 42 因子 / RSI / GBM / 行业分池 / 随机分池 —— 全部 ρ = 0.90~0.96。
想提高组合夏普，必须引入**非 beta 相关的资产**或**做空/对冲**，而不是在
A 股多头内部做文章。

这与 `CONCLUSION_2026-10-27.md` B 节第 6 条「非横截面资产：ETF 轮动
（宽基/行业/红利）、指数增强」指向同一处 —— 而它**至今没有被试过**。

### 同时更正结论文档的一处归因

`CONCLUSION_2026-10-27.md` 第三节说 0.75~0.79 的相关来自
「所有策略都从同一股票池选 TopK → 持仓天然重叠」。
**实测不成立**。该节的**结论**（框架内上限 0.88~1.03）不变，
但**原因**应更正为：所有策略共享市场 beta。
这条更正很重要——因为按错误的归因，会去试「换池」类解法（已证伪），
而正确的方向是「换资产类别」。

### 另一个诚实的观察

分池方案的收益是**前低后高**的形状：2023/2024 明显不如基线
（K=4 的 2023 只有 +0.07%），2025/2026 明显好于基线
（K=4：2025 +16.29% vs 基线 +9.06%）。
**没有任何一年全胜。**

这也提示了一个**选择偏差风险**：如果只看在 2025-2026 这两年
（结论文档已指出 2025H1 是所有变体共同的异常窗口），
K=4 看起来是"最优"（+16.3%/+6.7%）。**但 2025H1 本身就是异常窗口**，
在异常窗口上挑出来的最优格不可信 —— 这正是结论文档教训 ⑦ 说的
「所有子集都在某个窗口爆表 = 该窗口是共同异常，不是 alpha」。

## 六、给用户的行动含义

1. **主线不变**：`honest_composite`（25 因子，真实盘口径夏普 0.880 /
   +35.5% / −13.4% / 1190 笔）仍是当前最优单腿，维持纸面盘。
2. **不要做**：任何形式的"换股票池"（含市值分层、行业子池、随机子池）。
   机制上已被证伪，且这会浪费真金白银的持仓名额去换同一个 beta。
3. **下一个真正有希望的方向**：非 A 股多头资产腿
   （红利/低波 ETF、债券、黄金）→ 真正降低组合 β，或做空/对冲腿。
   这是唯一还能突破 0.88~1.03 框架上限的路径，且**至今未被试过**。
4. **3 年窗口搜参数是负价值的**（DSR: 夏普 1.5 需 12~17 年样本）——
   与本报告结论一致：不要再在 3 年窗口里搜变体，把证据留给纸面盘累积。

## 七、诚实声明

1. **本实验只有一个策略（honest_composite 25 因子）**，未在
   `rsi_71421` / `gbm_voltgt` 上复验。但"ρ=0.90 是 beta 驱动"这个结论
   是**结构性**的（任何 A 股多头组合都成立），单策略验证已足够支撑。
2. **本报告只证伪"分池能提夏普"**，不证伪"分池能降低相关"——
   事实上它**确实**降低了（随机 0.96 → 行业 0.90），只是幅度不够。
3. 合成组合的**换手成本**未单独建模（各腿独立计费后相加），
   但因结论是负向的（K=3/K=4 变差），这个简化不影响判定。
4. **子代理模拟器**未被使用——全部数字来自原生引擎 `BacktestExecutor`。

- **`yearly` 首年基线错误**：首年基线原用 `1.0`，而净值是绝对金额
  （~1e6）→ 2023 年收益被算成 2042960.53（垃圾值）。
  已修为 `nav[0][1]`（组合初始净值）。
- **universe 列表有重复**：`universe_from_instruments` 返回 5514 条，
  其中 `688665.SH` 出现两次 → 唯一代码 5513 个。
  基线（K=1）必须用**原始列表**跑才能与 v2 基准逐位对齐；
  分池（K>1）必须用**去重列表**，否则池规模统计错误。
