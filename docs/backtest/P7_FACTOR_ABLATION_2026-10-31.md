# P7 主腿因子消融 —— 主腿弱，是因子构成的问题吗（2026-10-31）

> **背景**：P6 的真正推论不是"把主腿权重 w 调小"，而是
> **主腿（honest_composite）夏普只有 0.87(main)，
> 袖套却有 1.62** —— 降 w = 用更弱的资产替换更强的资产，不是 alpha。
> → 真正该改的是**主腿本身**。
>
> **本实验唯一变量**：主腿的因子集合。袖套（P5 固定持仓集）、权重（w=0.50）、
> 成本与成交口径全部与 P3/P5/P6 定稿一致，基线门已通过
> （base25 组合夏普 1.4114 = P3 定稿 1.4114）。

ablation 43 / family 19 / greedy / weights / stability / oosval / walkforward / consensus）。

## 一句话结论

**没有任何规则臂通过 (a)~(e) 全部预注册判据 —— 因子消融证伪。** 主腿的弱不是「因子选错了」能修的，要么是这 25 个公式因子的信息量本身就到这里了，要么是问题不在因子层而在**信号构造或执行层**。

### 【决定性对照】规则臂在 oos 输给随机对照

- `drop_MAX` 组合夏普 **0.7819** vs 同 keep-count 随机对照最大 **1.1299**（3 个随机臂：1.1155, 1.1299, 1.1068） → 规则臂**输**随机，Δ(rule − rand_max) = -0.3480

→ oos 窗口里随机对照胜过基线：3/3；规则臂胜过基线：0/1。

**读法（必须两窗口合看）**：在 main 窗口上，9 个同 keep-count 随机臂**全部低于**基线（keep=15 组最大 1.3094；keep=20 组最大 1.3934；keep=22 组最大 1.3903，均 < 基线 1.4114；胜过基线 0/9）；而到了 oos 窗口，三个随机臂**全部高于**基线。同一批配置在两个窗口上朝相反方向移动 → 随机删减带来的差异是**窗口噪声，不是因子信息**。

**但这不构成"可以随机删因子"的许可**：随机臂在 oos 赢、在 main 输，方向不稳定；而规则臂 `drop_MAX` 在**两个窗口都输**（main 1.3992 < 1.4114，oos 0.7819 < 1.0691），且 oos 里被随机臂拉开 0.3480。

→ **结论：按规则删因子比随机删因子更差**。若一定要说"25 因子不是最优"，证据指向"存在某个未知的因子子集"，但**没有任何可预先指定的规则能挑出它** —— 这类结论无法落地，不能作为改稿依据。

## 工程与口径说明

### 等价臂交叉验证

`only_honest_high_ic` 的 20 个因子恰好 == `drop_MAX` 的 20 个
（已有 42f 研究里的"高 IC 公式族"本身一个 MAX 族都没有）→ 两臂必须产生**逐位相同**的净值。

- `drop_MAX|only_honest_high_ic`：逐位相同 ✓（727 vs 727 天）

### 已排除的混淆变量

- `min_cross = max(2, min(30, n_stocks//10)) = 30` 是**横截面行业内有效股票数**门槛，
  不是每只股票的因子票数 → **不受因子剔除影响**。
- 复合分是 `acc / wsum` 的 nan-aware 归一 → 缺某个因子的股票不被惩罚。
- 符号表 `_HONEST_FORMULAS` 是模块全局，逐臂跑完**硬断言已还原**，
  否则一个"翻符号"臂会污染后面所有臂（症状是"夏普莫名其妙"，极难归因）。
- 因子白名单走策略内置 `factor_allowlist` → **零生产代码改动**。

### 已知结构性限制

(f) 独立样本外证据结构性缺失（honest_composite A 股腿面板从 2021-05-11 起，OOS 起点正是那天 → 不存在窗口前长历史 A 股腿）。即使 (a)~(e) 全过，本实验也不自动改定稿，只产出候选与量化证据。
