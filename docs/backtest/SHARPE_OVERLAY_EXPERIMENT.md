# 夏普提升实验档案（Overlay 三杠杆 + 引擎确定性修复）

> 2026-10-12。承接"高胜率策略能否靠风控变好"：止损 A/B 已证伪出场端（胜率 61-69% 崩到 18-45%）。
> 本实验换**出场无关**的三条文献杠杆全部实测，并顺带修复了回测引擎并行路径不可复现的硬伤。
> 宇宙 500 只 × 2023-05-12→2026-05-08，口径同基线。
> 数据：`sharpe_overlay_experiment.json`（5×5）/ `sharpe_vol_sweep.json` / `sharpe_serial_verify.json` / `sharpe_vol_sweep_serial.json`。

## 0. 引擎确定性修复（本轮最重要的产出）

**发现**：`enable_parallel=True` 连跑 3 次同一回测，收益 77.55% / 79.51% / 107.42%——
并行数据加载（`DataLoader.load_multiple_stocks` 的 `as_completed` 收集）使 dict 插入顺序
受线程完成时序影响，下游按顺序迭代股票生成/执行信号，同日多信号的执行顺序与资金分配
路径分叉。`PYTHONHASHSEED` 压不住（是线程调度时序，非 hash）。

**修复**（`backtest_executor.py`，加载后按输入 `stock_codes` 顺序重建 dict）：
- 修复后验证：parallel ×3 + serial，交易序列 hash 逐笔一致（`797d612a2d6d`），final 完全相同 ✅
- 验证脚本：`backend/scripts/verify_determinism.py`（3 次 parallel + 1 次 serial，比对 trades hash）

**影响范围**：修复前所有 parallel 路径数字（含基线排行榜）带并行噪声，幅度可达收益 ±30pp。
**后续行动**：
1. 基线排行榜 + 止损 A/B 用修复后引擎重跑一遍，替换 JSON 与档案数字（约 30 分钟后台）
2. `verify_determinism.py` 转正式测试进 CI（建议 `tests/unit/backtest/test_determinism.py`）

## 3. 结论

**① rsi + vol 开关 25% 的真实价值是"回撤工程"，不是收益 alpha。**
- 夏普 0.307→0.664（2.2×）、回撤 -46%→-13.5%（砍 71%）、年化 +2.5%→+7.5%
- 但交易数 601→188（防御 560/723 天）：**收益提升来自"在坏时段空仓"**，不是策略本身变强。
  空仓期贡献零收益零波动，机械抬升夏普比。
- **阈值刀锋确认**：25% 上 0.664，30% 崩到 -0.19，40% 到 -0.76，非单调。20% 也只有 0.26。
  vol 开关 25% 是一个存在但不宽的甜点，稳健性中等——比止损路线诚实（止损是纯负），
  但达不到"稳健杠杆"标准。

**② 个股 MA200 门基本无效**：5 策略中 4 个持平或微降，stochastic 微升（0.77→0.80，年化 +1.2pp）。
不单独立项，可作为组合层弱增强保留观察。

**③ 市场 MA200 全进全出全线失败**（parallel 路径实测，方向在 serial 下待复验但预期一致）：
2023-2026 牛熊切换期防御 250-320 天，再入场滞后吃掉反弹，5 策略全降。**淘汰**。

**④ 强策略（stochastic/kdj）加任何防御都是负**：防御杠杆只对弱策略有意义。

## 4. 最终建议（给用户拍板）

1. **立即**：修复后引擎重跑基线排行榜（数字替换档案）+ verify_determinism 转 CI 测试
2. **rsi 升级判定**：不建议直接把"rsi+vol25"注册为独立策略——2.2× 夏普里有相当部分是
   空仓工程 + 单窗口单宇宙。建议做法：**组合层波动率择时**（stochastic 主力 + rsi 副仓，
   组合 vol 超阈值整体降仓），既保留 stochastic 的真实 alpha，又用 vol 开关管回撤，
   避免把刀锋阈值写死在单策略里。
3. **cci 无解**：各变体 0.15-0.32 全是地板，提升要换入场逻辑不是 overlay。
4. 待办（下轮）：组合层 vol 择时 A/B（stochastic 单独 vs +rsi 2:1 vs +vol 开关）。
