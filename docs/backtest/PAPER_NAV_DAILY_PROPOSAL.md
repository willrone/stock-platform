## 零、先纠正一个会导致事故的口径混淆

台账 §12.45 F 写的是"**方案 B = 前端曲线切到日频**"。
**字面执行会把赛马图毁掉。** 因为本项目里"净值曲线"有**三套互不相同的口径**：

| # | 口径 | 数据源 | 点数 | 回答什么问题 | 画在哪 |
|---|---|---|---|---|---|
| ① | **月频复利还原** | `strategy_race.py:380` `_months_to_nav(monthly)` | **36 点（3 年）** | 各策略**历史回测**谁更强 | `paper-portfolio` 页的 `StrategyRaceChart`（**唯一一张图**） |
| ② | **调仓日净值点（周频）** | ledger 的 `portfolio_value` | ~4 点/2 月 | 纸面盘**已实现**业绩 | `today-signal` 页只显示**点数**（`nav_points`），**没画曲线** |
| ③ | **每交易日盯市（total_return）** | `data/paper/<strategy>_nav_daily.json` | ~12 点/1 月 | 纸面盘**持仓期内回撤** | **全前端零引用**（`grep nav_daily src/` = 0） |

**"前端曲线切到日频"的字面后果** = 把 ① 换成 ③：
赛马图会从"3 年历史回测比较（36 点）"变成"当前纸面盘近 1 个月（12 点）"，
**比较对象和区间全变了** → 赛马图的语义被摧毁。

→ **方案 B′：① 不动，新增 ③ 的曲线，②③ 分开展示并各自标注口径。**

## 一、方案 B′：新增纸面盘日频净值曲线（前端）

### 1.1 落点

**`today-signal` 页**（`frontend/src/app/today-signal/page.tsx`）——
它已经在调 `/trading/performance`（单策略），已经拿到了 `nav_daily`（后端 :646 已挂），
只是**没画**。改动最小、语义最贴切（这页就是"今天这条线怎么样"）。

`paper-portfolio` 页是**多策略赛马**视角，塞单策略日频曲线进去会与 ① 混淆 → **不动**。

### 1.2 数据源（已就绪，无需后端改）

`GET /api/v1/trading/performance?strategy=<key>` →
`nav_daily: { available, basis, n_points, n_stale_points, updated_at, initial_capital, points[] }`

`points[]` 元素结构（`signal_service.py:183-250`）：`{ date, value, stale_price? }`
→ 前端 `RaceNavPoint { date, value }` **可直接复用**。

### 1.3 三条诚实披露必须透出（后端已做好，前端不能吞）

| 字段 | 含义 | 前端行为 |
|---|---|---|
| `available` | 有没有日频数据 | `false` → 明确显示"暂无日频盯市数据"及 `note`，**不能画空图** |
| `n_stale_points` / `stale_price` | 该点用的不是当日收盘价 | 点上标注（或图注计数），**不吞** |
| `updated_at` | 数据有多旧 | 图注显示"数据截至 X（产物生成于 Y）" |

### 1.4 口径标注（硬要求）

新图的图注必须写明与 ①③ 的区别，建议文案：

> 日频盯市净值（`total_return` 口径，每个交易日盯市；~12 点 ≈ 1 个月）。
> 与上方赛马图的**月频复利还原**（历史回测口径，36 点）**不是同一口径，不可直接对比**。
> 周频"调仓日净值点"另有其口径；**回撤以日频为准**（周频会低估）。

### 1.5 风险

- ①③ 两张图同框 → **口径造假**（点数、区间、含义全不同）→ 必须分开
- 12 点算不出稳定夏普 → 图上**不得**显示夏普/回撤结论，或明确标注"点数不足"
- `nav_daily` 产物由 cron `0294eb16149f`（工作日 18:20）产出 → 隔天看是常态，`updated_at` 必须显示

## 二、方案 D：历史区间回溯（ledger 重放）

### 2.1 要解决的缺口

方案 B′ 画的是 **cron 从 2026-11-02 起每天记的点**（~12 点）。
但 **ledger 里有 2026-10-30 起的全部成交流水** → 可以**回溯**出更早的日频曲线。

方案 B′ 与 D 是**两件事**：B′ 是"把已有的日频数据显示出来"，D 是"把历史补出来"。

### 2.2 动手前必须先解决的三个坑（只读审计已证实）

#### 坑 1：ledger 表头与数据行列数不一致 —— ✅ **已于 06:05 修掉**（§12.48 / `803131bd`）

`append_ledger` 现在固定写 **15 列** + 旧文件原子迁移。
→ 8 个 ledger 文件已迁移，**零值差异**（日期/价格/股数/金额/费用全部逐位相同）。
→ **本方案可以放心用 `csv.DictReader` 了**（这是修它的直接收益）。

#### 坑 2：ledger 的 `portfolio_value` 不能当历史净值点的权威值（**仍存在**）

2026-11-02 那批行的 `portfolio_value` 用的是 `adj_ratio = 1.0`（未乘后复权比值）：

| 线 | ledger.pv | holdings.last_value | 差额 |
|---|---|---|---|
| 22f | 1,001,156.93 | 978,982.93 | **+22,174.00** |
| rsi_71421 | 1,013,439.91 | 984,151.90 | +29,288.01 |
| honest_42f_neu | 998,438.49 | 936,671.49 | +61,767.00 |

→ 净值点一律用 `total_return_portfolio_value(positions, cash, adj_close, as_of)` 重算。

#### 坑 3：多资产线合并文件里的 leg=a 段是过期快照（**仍存在**）

`multi_asset_final_holdings.json` 的 A 腿是拷贝副本，A 腿后来被
`fix_adj_cost_backfill.py` 修好了，合并文件没跟着修 → 实测 **60/60 只**
`adj_cost` 是 `NaN`、`buy_date` 是信号日而非成交日。
→ 重建多资产线**必须从 `multi_asset_final_a_holdings.json` 取 A 腿**。

### 2.3 实现分四步

| 步 | 内容 | 量 |
|---|---|---|
| 1 | `backend/scripts/ledger_replay.py`：按 15 列定契约解析 + 逐笔重建任意日持仓 | 小 |
| 2 | 估值层接线：单线 `total_return_portfolio_value`；袖套 `sleeve_positions_value`（**不能套 A 腿逻辑**） | 小 |
| 3 | 产出：扩展 `paper_daily_nav.py`，加 `--as-of` / `--range` | 中 |
| 4 | 多资产线 | **不做**（见 2.5） |

### 2.4 语义选择（二选一，必须写进台账）

- `run_line`（生产代码）是**全清仓 + 从 positions 删除**（`paper_portfolio.py:996-1021`）
- `paper_daily_nav.py` 用的是**移动平均成本**

现有数据全是全清仓 → 两种实现结果**完全相同**（实测 7 条线逐位 0 差异），
**这个选择无法被现有数据证伪** → 选**全清仓**（与生产代码一致）。

### 2.5 多资产线：不做（B1）

A 腿用**后复权比值**、袖套用**前复权价直接乘股数**（前复权序列随分红重锚，做比值会系统性错算）
→ 两套口径**拼不到一条有经济意义的曲线上**。
B2 要引入袖套后复权数据源；B3 的曲线在袖套调仓区间内不可解释。
→ **推荐 B1：多资产线不做日频**（与 `paper_daily_nav.py:55` 的现有设计一致）。

### 2.6 验证锚点（不达标不算做完）

| 项 | 阈值 | 现状参考 |
|---|---|---|
| 重放 positions（shares/cost/buy_date）vs holdings 文件 | 逐位 **0 差异** | 7 条线实测 0 ✓ |
| 重放 cash vs ledger `cash_after` | 残差 **≤ 0.03 元** | 6 条线 ≤0.03 ✓ |
| 末点净值 vs `nav_history` 末点 | 差 **≤ 0.05 元** | 实测 0.00~0.02 ✓ |
| 缺行情日 | **必须显式标注**，不能静默用前值填充 | 待测 |

### 2.7 风险

1. **后复权序列是递推出来的** → 历史值会随数据更新漂移 → 曲线**不是可复现的历史事实**，
   是"按当前后复权序列回算的结果"。必须写进产物元数据。
2. **停牌/新股**：某日无行情 → 显式标注缺数（否则曲线骗人）
3. **袖套 21 个交易日调一次仓**：调仓间隔内持仓不变、只变价格 → 日频盯市要区分这两种变化
