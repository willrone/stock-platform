# 组合层波动率择时实验（stochastic + rsi 双腿）

> 2026-10-12。承接 overlay 三杠杆结论（`SHARPE_OVERLAY_EXPERIMENT.md`）：
> vol 开关对 rsi 有改善但阈值刀锋、不单独注册 → 尝试升级为组合风控。
> 口径：500 只宇宙 × 2023-05-12→2026-05-08，两腿各 50 万（组合 100 万），费率/仓位同基线。
> 数据：`data/strategy_baseline/portfolio_vol_experiment.json`（含分年）。
> 引擎：确定性口径（vol overlay 路径验证 parallel≡serial，逐笔一致）。

## 变体与结果（500 只宇宙）

| 变体 | 夏普 | 年化 | 总收益 | 回撤 | 组合波动 | 防御日 |
|---|---|---|---|---|---|---|
| C stochastic 单腿 100万 | **0.77** | **+22.6%** | +79.5% | -36.7% | 33.9% | - |
| C rsi 单腿 100万 | 0.31 | +2.5% | +7.3% | -46.0% | 50.3% | - |
| V1 静态 50/50 | 0.54 | +13.9% | +45.2% | -36.4% | 35.7% | 0 |
| V2 各腿自触发 vol25 | 0.45 | +4.3% | +12.9% | -18.3% | 10.7% | 649/475 |
| V3 组合 vol25（路径触发） | 0.53 | +8.1% | +24.9% | -19.9% | 17.5% | 509 |
| V3 组合 vol30 | 0.20 | +2.0% | +5.8% | -30.3% | 18.6% | 310 |

分年（V1 / V3-25%）：
- V1：2023 +26.4% / 2024 -1.4% / 2025 +20.4% / 2026 -3.3%
- V3-25%：2023 +28.2% / 2024 +7.4% / 2025 +1.1% / **2026 -10.2%**

## 结论：组合层 vol 择时**证伪**

1. **没有任何组合变体超过 stochastic 单腿**（夏普 0.77 / 年化 22.6% / 回撤 -36.7%）。
   单账户无杠杆架构下，**最优解 = 最强的单腿，不加任何 overlay/组合化**。
2. **diversification 稀释**：加 rsi 副仓（夏普 0.31、波动 50%）把组合夏普从 0.77 稀释到 0.54、
   年化从 22.6% 砍到 13.9%。弱腿拉波动不拉收益。
3. **vol 择时管回撤不管夏普**：V3 把回撤 -36%→-20%、波动砍一半，但夏普 0.54→0.53 原地踏步——
   砍掉的是低波动低收益时段，留下的时段并没有更高的收益/波动比。
4. **自触发死锁**（V2 暴露）：清仓后组合 vol 被自身压制，恢复条件 <0.7×阈值在空仓期
   难以满足 → 2025/2026 两腿收益归零（0%/0%）。全进全出的 vol 开关天然有"回不去"问题，
   组合层面更严重（防御日 509/723，2/3 时间空仓）。
5. 阈值刀锋在组合层面同样成立：25%→0.53，30%→0.20。

## 夏普研究的最终版图（四轮实验汇总）

| 路线 | 机制 | 结论 |
|---|---|---|
| 止损 A/B | 出场端 | ❌ 证伪：毁胜率（61-69%→18-45%） |
| 个股 MA200 门 | 入场门 | ⚪ 微弱正/持平，不够立项 |
| 市场 MA200 全进全出 | 市场择时 | ❌ 证伪：全 5 策略失败 |
| 单策略 vol 开关 | 时间占比 | ⚠️ 只对 rsi 有效（0.31→0.66），阈值刀锋+空仓工程，不单独注册 |
| 组合层 vol 择时 | 组合风控 | ❌ 证伪：无变体超单腿，diversification 稀释 + 自锁死 + 夏普原地踏步 |

**"提高夏普"的诚实答案**：现有 16 策略中，stochastic 夏普 0.77（年化 22.6%/回撤 36.7%）
与 factor_ranking 0.92（年化 11.5%/回撤 10.6%）**就是天花板附近**；overlay 类外挂
（MA 门/vol 开关/市场择时）在确定性口径下没有一个能把它们推高。
真正提高夏普的路径在**策略内部**（信号质量/因子组合），不在外围风控包装。
stochastic 的 36.7% 回撤是它 22.6% 年化的代价——要同时改善两者需要新的信号逻辑，
例如它的入场条件收紧（更严格的 K 值阈值/形态过滤），这是下一类值得试的改动。
