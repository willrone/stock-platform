## 0. 一句话结论

- **「A 股腿没有 2021-05-11 之前的历史」是错的。** 那个边界是 Alpha158 **面板**的边界；生产 `honest_composite` 默认 `use_panel=False`（`honest_composite_strategy.py:199`），25 个因子全部由 close/high/low/volume **现场算**（`:343-346`）。
- `data/qlib_data/features_full/`（5513 只 / 每股票全历史）与 `features/day` 在 main 窗口**逐位等价**：total_return / sharpe_ratio / max_drawdown / win_rate / 交易笔数 **diff 全部 = 0**（验证门通过）。
- 于是 A 股腿 25f 生产配置的**跨窗口夏普曲线**（引擎口径）出来了：`w2013` **0.8099** / `w2016` **-0.1903** / `w2019` **1.2295** / `oos` **0.7297** / `main` **0.8796** → 均值 **0.6917**、极差 **1.4198**、标准差 **0.4728**。
- **推论**：一直被引用的「主腿 0.87 / 0.72」落在曲线的**偏上区间**；「A 股腿 50%」这个定稿是在两个偏高的窗口上定出来的；P6 的 w 曲线（main 最优 0.20）本质是**主腿强弱随窗口漂移**，不是一个可固定的数。
- **定稿不变** —— 本实验只补充证据，没有新增任何资产侧规则；但它把「第三样本结构性缺失」这个借口从 P6/P7/P8/P9 的案卷里拿掉了。

## 1. 前提纠正：2021-05-11 是「面板」边界，不是「数据」边界

P6 / P7 / P8 / P9 的结论里都写着同一句话：

> 「`honest_composite` A 股腿面板从 2021-05-11 起，没有窗口前的 A 股腿历史 → 独立样本外证据结构性缺失」

这句话把两件事混成了一件：

| | 现状 | 边界来源 |
|---|---|---|
| Alpha158 面板（17 因子） | 生产**不用**（`use_panel` 默认 False） | `data/qlib_data/features/day/` 的两段拼接 |
| 25 个基础公式 | 生产**全部在用** | close/high/low/volume（价格即可） |

而 `data/qlib_data/features_full/`（`backend/scripts/build_full_history_features.py` 的产物，5513 只 / 188 列 / 每股票全历史）**早就在本地**：实测 4330 只（78.5%）在 2021-05-11 之前就有数据，最早回溯到 1990-12-19。

代码清单来自 `universe_from_instruments(QLIB_OFFICIAL)`（PIT 全宇宙），与 `features/day` 无关 → **唯一差别就是每只股票的数据覆盖**。

## 4. 长历史专属的 PIT 修复：涨跌停幅度必须按日期

长历史暴露了一个**现行代码看不见的口径错误**：`limit_pct` 用的是**现行**板块规则（创业板/科创板 20%），但**创业板 2020-08-24 注册制之前只有 10%**。用 20% 去掩 2016~2019 的创业板，会把「当日真的涨停（买不到）」的票放过去 → 成交价不可实现 → 长历史被系统性污染。

修复：`execution_rules.limit_pct_at` / `limit_up_mask_matrix_at`（按交易日 PIT），策略改用新函数。**关键性质：2020-08-24 之后的窗口与原实现逐位相同**，所以这是**纯长历史修复，不动任何已定稿数值** —— 回归门 `backend/scripts/p10_limit_pit_regression.py` 覆盖该断言，且 P10 验证门重跑后 main 窗口 diff 仍全部 = 0。

实测：修复前后三个长历史窗口的数值**完全一致**（0.8099 / -0.1903 / 1.2295）→ 掩码伪迹**不是** w2016 窗口负夏普的成因。

> 为什么会一致：本策略的 MIN 因子选的是「远低于 N 日最低价」的票，这类票几乎不可能当日涨停 → 涨停掩码在买入端基本不触发。结论是**否定性的但有价值的**：排除了一个看起来很可疑的解释。

## 5. 对既有结论的影响

| 既有结论 | 原依据 | 新证据 | 影响 |

## 6. 仍然开放的问题

1. **主腿在坏窗口里是亏的，还是只是被 beta 拖累？** → 需要同窗口的等权/指数基准算超额夏普，才能区分「策略失效」与「市场下跌」。这决定了「该改主腿」到底该改什么。
2. **w 随状态漂移能不能落地？** → 需要一个**不依赖窗口**的「主腿强弱」状态量（例如主腿自身的滚动夏普 / 相对基准强弱），用它做动态权重，而不是继续找固定 w。
3. **组合的长历史** → 受限于 ETF 本地数据起点，需要另找数据源。
