## 2. 合规边界（硬判据，任何对外可见的东西上线前逐条自查）

证券投资咨询在中国是**特许经营**：《证券法》120、160 条，《证券、期货投资咨询管理暂行办法》3、12 条（机构须持牌 + 个人须取得从业资格并挂靠持牌机构）；《刑法》225 条非法经营罪。证监会另有《关于加强对利用"荐股软件"从事证券投资咨询业务监管的暂行规定》——**卖软件本身就在射程内**。

已判例（不是推测）：
- 某网站股票"圈子"圈主，每月约 520 元会费提供分析/预测/建议 + 直播答疑，违法所得 1200 余万元 → 非法经营罪，**判 2 年 4 个月、罚金 1300 万、追缴全部违法所得**（福建证监局认定其无资质；法治日报/财联社 2024-11-03）。
- 吴某平 2017-08~2022-06 经小鹅通等收**课程费、会员费、荐股分成** 255.17 万元，申辩"我卖的是课程不是荐股"**未被采纳**，罚没 455 万元（广东证监局）。
- 北京延庆法院 2026-05 案例：以"培训带盘"名义收费 4 万元 → 合同无效、返还。官方口径：**投教包装≠合法、资格考试≠从业资质**。
- 监管强度参考：截至 2026-02 底，年内证监会已对 8 家**持牌**投顾机构采取行政监管措施，4 家暂停新增客户。平台侧：抖音单月治理股市违规账号 3600+、违规内容 15000+ 条。

### 三红线判据（任意为"是"即不合规）
1. 是否有**具体个股的买卖建议/预测**被对外展示？
2. 是否有**收益承诺、预期收益率、"稳健超额收益"式宣传文案**对外出现？
3. 是否向**公众收费**？

**自用 = 三个都为否。** 今天平台上的这三条各有一处现存痕迹：`/today-signal` 的"需信号版"付费引导（1+3）、`/app/templates/page.tsx` 的"获取超额收益 / 追求稳健的超额收益"（2）、`/pricing` 的"开通信号版"（3）。自用化改造必须处理它们（至少：对外不可达）。

### 以后若要重新变现，只允许这两种形态
- 卖**工具/回测/数据/算力**——不输出个股建议、不承诺收益、不代客决策。
- 挂靠持牌机构（个人几乎不可行：需从业资格 + 机构牌照）。
"卖选股信号收费 / 带单 / 付费社群 / 荐股分成" —— **永久排除**，不是因为收益不好，是因为它构成非法证券投资咨询。
